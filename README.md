# NF会計システム
NF会計システムの使い方について説明します。

## 準備（親機にする PC で 1 回だけ）
1. Python 3.11 以上を入れる（インストール時に「Add python.exe to PATH」にチェック）
2. このフォルダでコマンドプロンプトを開き、必要なライブラリを入れる
   ```
   pip install flask requests
   ```

## 起動
| 使い方 | 起動のしかた |
|---|---|
| この PC だけで使う | `python web_main.py` |
| 親機として、同じ Wi-Fi の子機からも使う | `レジ起動（親機）.bat` をダブルクリック（または `python web_main.py --lan`） |

親機として起動すると、子機から開くアドレス（例：`http://192.168.10.106:5002/`）が表示されます。
初めて起動したときに Windows のファイアウォールの確認が出たら、「プライベート ネットワーク」で許可してください。

## 子機（親機以外の PC・タブレット）で使う
1. 親機と同じ Wi-Fi につなぐ
2. ブラウザで、親機に表示されたアドレスを開く（アプリのインストールは不要）
3. 端末の名前と「子機のパスワード」を入れてログイン

- 子機のパスワードは、親機の Settings →「子機の接続」で決めます。変えると、ログイン中の子機はログインし直しになります。
- 期間・担当者・未確定の入力は端末ごとです。売上の個数は親機にまとめて保存され、全端末で共有されます。
- Settings の「子機の接続」で、ログイン中の端末の一覧を確認できます。

## ダッシュボードを Google スプレッドシートで共有する
親機が 1 分ごとに売上を Google スプレッドシートに送ります。スプレッドシートを共有すれば、VPN なしでみんなが見られます（親機はインターネットにつながっている必要があります）。

1. 共有用のスプレッドシートで「拡張機能」→「Apps Script」を開き、`share/dashboard_sheet.gs` の中身をすべて貼り付けて保存する
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。「次のユーザーとして実行：自分」「アクセスできるユーザー：全員」でデプロイし、出てきた承認を許可する
3. 表示された「ウェブアプリの URL」（…/exec）を、レジの Settings →「ダッシュボードの共有」に入れ、「スプレッドシートに売上を送る」にチェックを入れて保存する
4. スプレッドシートを「リンクを知っている全員（閲覧者）」で共有する

ウェブアプリの URL を知っていると誰でもデータを送れてしまうので、人に教えるのはスプレッドシートのリンクだけにしてください。

## 支払い方法
商品カードの「現金」「PayPay」「Square」の 3 段で入力します。
- 現金・PayPay：レジで手で入力する（PayPay は Square を通さずに受けたもの）
- Square：Square アプリの会計を親機が自動で取り込む（自動取り込み中は ＋／－ を押せない）

キーボードでは F1 で入力中の分をまとめて現金に、F2 で Square に、F3 で PayPay にできます。

## 直近の会計
レジ画面の右に、販売中の期間で確定した会計（Square から取り込んだ会計も）を新しい順に出します。押すと商品ごとの内訳が開きます。
ほかの端末で確定した会計もすぐに出ます。スマホでは商品の下の「直近の会計」を押すと開きます。
表示するだけなので、入力や取り消しはこれまでどおり商品カードで行ってください（テストの会計は親機を起動し直すと消えます）。

## 値段を変えるとき
Settings のメニューで値段を変えてかまいません。売上の金額は会計を確定したときの値段で記録しているので、変える前の売上は変わりません。
Square から取り込んだ会計は、Square で実際に払われた金額で記録します（Square 側で割引した場合もその金額）。

## 注意
- 親機を止めると子機も使えなくなります。親機はスリープしない設定にし、電源につないでおいてください。
- Square の自動取り込みは親機が行います。取り込み先は、最後に販売を始めた端末の期間です（テスト・調整は除く）。
- 学校などの Wi-Fi では端末どうしの通信が禁止されていることがあります。その場合は、ポケット Wi-Fi やスマホのテザリングで専用のネットワークを作ってください。
